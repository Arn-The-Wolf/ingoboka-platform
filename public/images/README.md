# Images Directory

## How to Add Your Photos

Replace the placeholder images in this directory with actual photos following the specifications in `RWANDAN_IMAGERY_GUIDE.md` at the project root.

### Priority 1 Images Needed:

1. **Hero Section**
   - `hero/family-home.jpg` or `hero/family-home.webp`
   - Dimensions: 1920x1080px minimum
   - Young Rwandan family at modern home

2. **Testimonials (3 photos)**
   - `testimonials/professional-woman.jpg`
   - `testimonials/business-owner.jpg`
   - `testimonials/parent-family.jpg`
   - Dimensions: 400x400px (square)

3. **Product Categories (6 photos)**
   - `products/health-insurance.jpg`
   - `products/life-insurance.jpg`
   - `products/motor-insurance.jpg`
   - `products/agriculture-insurance.jpg`
   - `products/business-insurance.jpg`
   - `products/education-insurance.jpg`
   - Dimensions: 1200x800px

### Image Optimization:

Before adding images:
1. Resize to correct dimensions
2. Compress with TinyPNG or similar (target < 300KB for hero, < 150KB for products)
3. Convert to WebP format for better performance
4. Keep JPG as fallback

### File Naming:

- Use lowercase
- Use hyphens for spaces
- Use descriptive names
- Example: `health-insurance.jpg` not `IMG_1234.jpg`

See `RWANDAN_IMAGERY_GUIDE.md` for detailed specifications.
